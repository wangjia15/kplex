These presets were exported from K-Plex at `809510f3edb5027848ea3cd6bcbf929dc051031d` before retiring them from the built-in set. Each file is an independent `kplex-preset` package with its category values, assignment/rules, colors, layout and English help. They contain no notes or active lenses.

Open **Settings → K-Plex → Canvas behavior → Views → Facets → Manage presets**, select **Import**, choose a JSON file and preview it. Import adds a saved preset; it does not select it or modify notes. Review any existing-ID collision before replacing a definition. The installed library's existing size limit still applies; import the presets you use.

Removing a built-in does not delete a saved user definition. An old canvas selection whose preset existed only as an inherited built-in remains recoverable by importing its original ID. Publishing's exported category labels are readable English literals instead of the former missing translation-key fallbacks.
